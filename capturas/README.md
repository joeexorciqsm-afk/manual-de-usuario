# Capturas de pantalla

Coloque aquí las capturas del sistema VORTEX con estos nombres exactos.
`generar_manual.py` las incrusta en el manual en este orden.

| Archivo | Pantalla | Figura en el manual |
|---|---|---|
| `figura1.png` | Módulo Cliente — Solicitar servicio | Sección 2 |
| `figura2.png` | Administrador — Inicio (panel de resumen) | Sección 3.2 |
| `figura3.png` | Administrador — Clientes y solicitudes | Sección 3.3 |
| `figura4.png` | Administrador — Inventario de piezas | Sección 3.4 |
| `figura5.png` | Administrador — Reportes y estadísticas | Sección 3.5 |

Formatos aceptados: `.png`, `.jpg`, `.jpeg`.

Las imágenes se insertan a 6.3 pulgadas de ancho y la altura se ajusta de forma
proporcional, por lo que conviene que todas tengan la misma relación de aspecto
(las capturas originales son de 1024 × 642 píxeles).
